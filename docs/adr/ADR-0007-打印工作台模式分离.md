- 状态：partially superseded by ADR-0009（模式分离仍有效；单模板和四个静态入口已取代）
- 日期：2026-09-23

> 历史决策记录：当前多模板、唯一编辑操作区和“仅暴露真实能力”口径以 ADR-0009 为准。本文件中的单活动模板和四个入口不再是现行验收要求。

# 背景

当前记录视图插件打开后直接展示完整 `vue-print-designer`，把高频的查看/打印任务与低频的模板编辑任务混在一个页面。用户需要在真实记录中先确认打印结果，而不是先理解设计器工具栏。竞品“排版打印”的有效交互是默认预览、点击“编辑”后进入设计器。

# 决策

1. 插件外层分为“打印预览模式”和“编辑模式”。默认进入打印预览模式，编辑器只在用户明确点击“编辑”后展示。
2. 打印预览模式复用引擎生成的单条 HTML 预览，保留真实记录值；打印/PDF/批量入口集中在该模式的顶部操作区。
3. 模板目录先表达当前表的唯一活动模板：MVP 不引入多模板切换、共享或权限模型；“新建模板”只表示从自动模板开始新的未保存编辑。
4. 编辑模式的外层入口统一为“数据源”“组件”“页面设置”“设置”；真实 `vue-print-designer` 仍负责画布、元素属性和底层排版能力，不另造画布。
5. 不在本 ADR 中解决 `BUG-0002` 的预览/打印分页偏差；该问题继续按独立缺陷验收。

# 后果

- 高频打印用户首先看到记录与打印结果，工程恢复按钮不再占据主操作区。
- 单条预览和当前文档打印开始共享引擎 HTML 来源，但实际页数一致性仍需 `BUG-0002` 的真实 E2E 关闭。
- 当前模板存储契约不变，仍按 base/table 保存一个活动模板。
- 组件面板、数据源目录和页面设置的细分交互依赖锁定引擎能力；本切片先统一入口和模式，不承诺后置的签名、检测器、二维码或多模板能力。
