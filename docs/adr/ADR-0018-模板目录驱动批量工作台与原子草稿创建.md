- 日期：2026-10-08
- 取代：ADR-0017 的左侧批次目录、批量禁止切换模板决定
- 保留：ADR-0017 的批量编辑、保存后原记录原布局原子重渲染；ADR-0009 的模板唯一事实源；ADR-0011 的候选原子提交

# 背景

Goal v9 把“本次打印”记录摘要作为批量预览和批量编辑的左侧目录。正式验收表明，这造成单条与批量使用两套导航：进入批量后模板目录消失，用户不能直观理解“选择一个模板打印一条或多条记录”，也不能在保留记录选择时切换模板。

同次验收还发现新建默认模板会进入空白工作区。当前默认分支传入 `null`，由 DesignerAdapter 间接生成模板；UI 在设计器加载、数据绑定和首屏渲染完成前缺少统一事务边界，失败可能留下半创建状态。

# 决策

1. 模板目录是预览模式的唯一左侧导航。`single-preview` 与 `batch-preview` 显示同一目录；`single-edit` 与 `batch-edit` 均为扩大画布隐藏目录，并使用唯一数据源/组件侧栏。
2. 批次记录只属于 `BatchPrintSession`。已选数量在右侧当前模板工具栏展示；详细记录摘要可进入次级信息，不占据左侧导航。
3. 批量预览允许切换模板。切换时保留原记录顺序与旧 canonical pages，使用目标模板完整重渲染；成功才同时提交模板选择与页面，失败保持原选择和旧预览。
4. 右侧当前模板工具栏统一承载表/当前记录或已选数量、选择/重新选择、退出批量、PDF、打印和编辑模板。顶层产品栏只表达“多维打印”身份，不拥有第二套业务动作。
5. 批量编辑隐藏模板目录，以唯一数据源/组件操作面与真实设计器占据工作区；工具栏替换为返回预览和唯一保存，隐藏模板切换、打印/PDF。返回预览前必须经过未保存草稿决策；返回后恢复进入编辑前的模板目录选择，批次记录、顺序和排版保持不变。
6. 【由 ADR-0023 修订】新建空白或自动生成模板必须先生成明确模板对象。创建事务依次完成模板生成、设计器加载、数据绑定和首屏渲染；全部成功后才提交草稿 ID、名称、目录选择和编辑态。默认、连续、标签不再是模板创建类型。

# 验证

- `CT-UX-09`：两种预览表面显示模板目录、两种编辑表面隐藏目录；右侧工具栏动作唯一。
- `CT-BATCH-06-UI`：预览切换模板保留三条记录并原子刷新；编辑隐藏目录，返回恢复旧选择；失败保持旧选择和预览。
- `CT-TPL-05/06`：空白和自动生成两种创建方式均传入明确对象；加载/绑定/首屏失败零状态提交。历史三排版创建证据不再作为现行验收。
- 932×540、700×540、1200×700 的批量预览和批量编辑批准稿。
- 真实 `vue-print-designer`、全量测试、生产构建和正式灰度 Base 验收。

# 边界

本决策不修改模板协议、打印/PDF算法、字段绑定、权限或发布范围。正式发布仍需单独授权，且只允许“多维打印”应用与灰度企业 `F225904757`。
