<title>ADR-0004 — 记录视图构建与空白页修复</title>

- 状态：accepted（本地构建）；宿主运行待验证
- 日期：2026-09-21

# 问题

用户打开原网页为空白，同时指出该产物只是独立 Demo。调查确认原 Vite 输出使用根绝对资源路径，且没有飞书记录视图所需的 `app.json`、`block.json`、官方 Webpack 插件或 Opdev 上传链。

# 决策

移除 Vite 构建入口，采用官方 Vue 记录视图模板对应的 Webpack 形态。生产输出固定到 `record-view/dist`，HTML 只引用相对资源。App ID 放在上级 `app.json`，BlockTypeID 放在 `record-view/block.json`。

`@lark-opdev/cli@3.4.4` 与 `@lark-opdev/block-bitable-webpack-utils@0.1.7` 使用了 npm 安装时恢复的内部依赖；CLI 必须在其它依赖之后安装，当前 lockfile/安装目录已通过 `opdev --version` 与构建验证。`@oclif/plugin-help` 拉入的 `lodash.template@4.18.0` 缺失 `assignWith`，使用 npm override 固定到 `4.5.0`，`create/upload --help` 已恢复。

# 验证

- `npm test`：44/44。
- `npm run build`：成功；生成 `project.config.json`、`index.json` 和相对资源 HTML。
- 最初 BlockTypeID 为空时保持显式阻断；取得平台生成值后才写入并上传，没有伪造 ID。

# 后果

本地结构已经是记录视图插件代码包，不再是 Vite 独立 Demo；真实 BlockTypeID 和 Opdev 上传已完成。但没有测试版本安装与真实 Base E2E 前，空白页只能说已修复其已确认的构建原因，不能宣称飞书内已验证不再空白。
