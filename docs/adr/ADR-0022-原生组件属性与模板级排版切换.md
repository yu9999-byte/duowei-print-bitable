<title>ADR-0022 — 原生组件属性与模板级排版切换</title>

- 状态：partially superseded by ADR-0023（九组件与原生属性面板继续有效；模板级排版新建已废止）
- 日期：2026-10-09
- 关联：`FR-DES-02/05/14/15`、`SPEC-UX-03/13/14`、ADR-0009、ADR-0013、ADR-0014、ADR-0016、ADR-0018

# 背景

当前编辑工作台只在左侧提供文本、图片、页码、表格和横线五个创建入口，并在初始化时关闭了 `vue-print-designer@1.7.39` 的原生属性面板。用户虽然能把组件拖入画布，却无法在选中图片、文字、表格等元素后设置图片来源、变量、位置、尺寸、层级和数据行为。默认、连续、标签三种排版也只能在模板目录新建，进入编辑后无法确认当前排版或安全创建另一种排版。

如果在多维打印外层再开发一套图片、文字或表格属性编辑器，会复制引擎能力并形成第二个属性事实源；如果把排版切换做成无提示原地转换，又会覆盖当前模板或丢失未保存修改。

# 决策

1. 组件创建由多维打印左侧“组件”面板负责；组件属性继续由真实 `vue-print-designer` 的原生属性面板负责。外层不复制图片、文字、表格或形状属性编辑器。
2. 左侧组件目录固定为九个已由锁定引擎提供的标准组件：文本、图片、页码、表格、条形码、二维码、横线、矩形、圆形。`multiLabel` 是标签排版结构，不作为普通组件入口开放。
3. 设计器初始化只关闭重复的元素库和结构面板，不再主动关闭属性面板；模板目录、保存、打印和 PDF 等重复产品入口仍按 ADR-0009/0018 由外层工作台拥有。
4. 页面纸张设置继续使用真实设计器已有的纸型、方向等入口；没有第二套外层“页面设置”。组件的来源、变量、位置尺寸、层级和数据行为都由右侧原生属性面板编辑。
5. 【已由 ADR-0023 取代】编辑侧栏不得再通过“排版”创建另一份模板；默认、连续、标签归入当前模板的批量排版设置。
6. 【已由 ADR-0023 取代】排版切换保持当前模板 ID 和模板数量不变，并采用候选渲染后原子提交。
7. 【已由 ADR-0023 取代】批量排版设置的脏草稿、忙碌、只读守卫由当前模板统一负责。
8. 【已由 ADR-0023 取代】批量编辑继续保留记录会话与全量投影，但不再创建排版草稿或目录项。

# 后果

- 用户拖入图片后，可直接使用引擎原生属性面板设置图片来源、上传图片、图片变量、位置尺寸、层级和数据行为；其他组件沿用各自真实属性能力。
- 产品只维护组件目录、当前模板批量排版设置和工作台动作，属性 schema 与实际渲染继续由锁定引擎负责，减少二次实现和升级分叉。
- 条形码、二维码在当前 MVP 中只代表引擎现成标准组件；业务编码规则、自研渲染器、扫码校验或行业条码方案仍需后续规格。
- 【历史结果，已由 ADR-0023 取代】本版曾以“安全新建”生成未保存排版草稿；现行实现改为同一模板内候选渲染与原子切换。
- 当前实现仍受 `vue-print-designer@1.7.39` 的原生属性能力与授权边界约束；升级引擎时必须重新执行属性面板和九组件契约测试。

# 验收证据

- `tests/designer-components.test.ts`：九组件分组、唯一性及 `multiLabel` 不作为普通组件。
- `tests/template-layout-choice.test.ts`：当时的安全新建证据只作为历史；现行同模板切换、迁移和事务验收见 ADR-0023/PHASE-06。
- `tests/designer-adapter.test.ts`：工作台只关闭重复元素库/结构面板，保留原生属性面板。
- `tests/workspace.test.ts`、`tests/workspace-presentation.test.ts`：九组件与属性面板相关证据继续有效；“数据源 / 组件 / 排版”侧栏已被现行“数据源 / 组件＋批量工作区排版设置”取代。
- 本地真实设计器：932×540 与 700×540 下九组件可达；图片拖入后原生属性面板可编辑来源、上传、变量、位置尺寸、层级和数据行为；默认→连续→标签的单条/三条批量草稿均保持记录会话并完整投影。
- 全量 `npm test` 206/206，生产构建 `assets/main.180d1d4a.js` 通过，仅保留既有三项 Webpack 体积告警。

# 复议条件

若锁定引擎的原生属性面板无法满足已确认的具体业务属性，先记录缺失属性、对应组件、真实场景和引擎证据，再决定扩展适配层或升级引擎；不得直接复制整套属性编辑器。若用户要求不同排版之间无损转换，需要另立模板转换协议和迁移验收，不能扩大本决策中的“新建独立草稿”语义。
