# ADR-0031 连续排版按内容高度接排

- 状态：本地候选，2026-10-15；待正式环境验收。
- 修订 ADR-0014 第 3 条与 SPEC-CONT-02。

连续模式原先以整页高度重复，与默认分页内容位置几乎相同。改用全部组件最大底边加 16px 留白作为固定区段高度，上限为基础纸张高度；保持组件坐标，底部日期、页脚也参与计算。最终长纸高度为区段高度乘记录数。内部主动留白不压缩，原生 multiLabel 输出链保持不变。

批量编辑共用同一高度计算，但回收时恢复基础模板原纸张高度，禁止将紧凑长纸尺寸持久化为基础画布。多页、表格、动态高度等既有限制不变。默认、标签及模板身份不变。

验收包括 2/3/10/50 条真实引擎 HTML 和 PDF、连续编辑保存后切回默认、失败恢复以及正式环境切换。未发布前不能把候选验证当作线上结果。
