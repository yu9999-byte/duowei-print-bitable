# ADR-0014 连续纸采用原生单列长纸排版

- 日期：2026-09-30
- 状态：已灰度并通过正式 Base 核心流程；PDF Blob 可观测候选已本地 Green，待发布后正式文件、系统打印与失败恢复验收再转 accepted
- 关联：`FR-BATCH-05`、`SPEC-CONT-01/02/03`、PHASE-04、BUG-0002

## 背景

竞品把“连续”作为独立批量排版。锁定的 `vue-print-designer@1.7.39` 没有公开 continuous API，但原生 `multiLabel` 能在一个最终 `canvasSize` 内按数组逐项复制首格内容。此前不允许入口，是因为没有证据证明长纸高度、50 条输出和原生 PDF 不会被截断。

## 决策

1. 连续模板是独立模板类型，由 `ext.batchLayout='continuous'` 标识；不在批量态临时切换默认模板的输出含义。
2. 首版连续模板只支持单页、固定高度、非关联的普通字段。表格、关联明细、`autoHeight`、`autoPaginate`、多页模板和标签网格明确拒绝，避免无法证明的动态高度和嵌套分页。
3. 输出时不拼接应用 DOM。`ContinuousLayout` 把原模板临时转换为引擎原生的单列 `multiLabel`：每条记录占一个原模板高度，最终纸张高度为 `recordHeight × recordCount`，间距为 0，记录顺序沿用已提交批次。
4. 每条记录独立执行既有多字段 Token 解析，形成数组行；预览和浏览器打印复用一个引擎 HTML 长页，PDF 由引擎一次原生导出。输出完成后恢复编辑模板和首条运行时变量，业务值不写入模板。
5. 7 条和 50 条真实引擎隔离试验是实现门，不是正式交付证据。正式 Base 必须验证模板保存重开、真实记录值、取消/重选/退出、PDF尺寸，以及系统打印对超长自定义纸张的处理。系统打印物理结果未通过前，BUG-0002 不关闭。

## 已有证据

- `tests/continuous-layout.test.ts` 覆盖顺序、最终高度、多字段值和结构拒绝。
- `tests/designer-adapter.test.ts` 覆盖一个长页、模板恢复和一次原生导出。
- `tests/browser/continuous-engine.ts` 使用安装的真实引擎生成 7 条与 50 条；两者预览均为一个引擎页面，每条订单值各出现一次。
- `artifacts/continuous-engine-7.pdf` 为单页 `595.502 × 1039.49 pt`，`artifacts/continuous-engine-50.pdf` 为单页 `595.502 × 7425.01 pt`。头、中、尾抽查包含第 1、26、50 条，没有观察到截断。
- 产品实际组合出的 `artifacts/continuous-print-7.html` 与 `artifacts/continuous-print-50.html` 已交给 Chrome 152 的打印引擎执行 `print-to-pdf`。输出 `artifacts/continuous-chrome-7.pdf` 与 `artifacts/continuous-chrome-50.pdf` 均只有一个物理页，页尺寸分别为 `595.92 × 1039.92 pt` 与 `595.92 × 7424.88 pt`；文本抽取和整页渲染确认第 1 至 7 条、第 1 至 50 条完整且顺序正确，没有分页、截断或漏记录。
- 上述 Chromium 证据证明浏览器打印引擎能遵循当前长纸 `@page`，但不等于飞书正式容器里的系统打印对话框或具体打印机驱动已经验收；因此状态仍保持候选，`BUG-0002` 不关闭。
- 小组件 `1.0.24` / 应用 `1.0.20` 已仅向 `F225904757` 灰度。正式 Base 已验证连续模板保存刷新重开、三条和十条真实订单在同一 `page-0` 中按序完整展示、取消重新选择保持原批次、退出恢复当前记录，以及一次浏览器打印/PDF入口触发。系统打印物理页数、正式下载 PDF 文件内容和失败恢复仍未取得，因此 ADR 尚不转 accepted。
- ADR-0015 的本地候选把连续导出改为先取得真实引擎 PDF Blob，校验文件头、页数和大小后下载，并回显结构结果；139/139 与生产构建通过。该候选尚未上传，不能替代正式长纸 PDF 的尺寸和视觉验收。

## 后果

- 用户通过“新建连续模板”明确选择连续排版；批量目录在预览和编辑状态均显示“连续排版”，保存后按原记录顺序重建长纸。
- 普通默认模板和标签模板的行为不变。
- 当前候选不支持关联明细和动态长文本连续排版；该限制必须可见且不能静默降级为默认模式。
- 浏览器/打印机是否支持超长自定义纸张取决于实际打印驱动，正式验收失败时保留 PDF 能力并重新评估入口文案或支持范围，不能声称物理连续纸已完成。
