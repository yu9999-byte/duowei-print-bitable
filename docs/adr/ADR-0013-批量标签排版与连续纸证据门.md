# ADR-0013 批量标签排版与连续纸证据门

- 日期：2026-09-30
- 状态：已采纳；标签三条真实预览/PDF 已在灰度正式环境通过，完整验收未结束

## 背景

已锁定的 `vue-print-designer@1.7.39` 有原生 `multiLabel` 元素。打印渲染会读取 `dataVariable` 指向的数组，按行优先/列优先在同一纸张内复制首个标签的元素，超出容量时生成下一页。该能力不是把多个独立 HTML 文档并排。引擎没有公开的“连续纸模式” API；任意修改 DOM 高度不能证明浏览器和 PDF 的最终纸张一致。

## 决策

1. 默认批量仍保持一条记录一份引擎文档。标签是独立布局，不复用默认模式的“页面数等于记录数”不变量，也不调用逐记录 `exportBatchPdf` 拼标签。
2. 标签模板必须是单页、一个 `multiLabel` 网格、首格内至少一个可打印元素；网格必须完整落在最终 `canvasSize` 内。超界、无效尺寸、表格或数据绑定的页外装饰元素明确拒绝，不能静默裁切或复制错误内容。
3. 同一组件的多个字段仍由既有 `prepareTemplateForOutput` 转成临时合成变量。每条记录生成一个数组行；一次载入临时标签模板，一次设置数组变量，调用真实引擎预览/PDF。输出后必须恢复原运行时模板和变量，不持久化业务值。
4. 主预览与浏览器打印共用同一缓存 HTML；标签页数按 `ceil(记录数 / 行列容量)` 核对。PDF 使用一次引擎 `export({type:'pdf'})`，不得改用引擎外自绘画布。
5. 连续模式当时暂不显示可点击入口；其后证据门已由 ADR-0014 的真实引擎 7/50 条长纸与原生 PDF 试验满足，实现转入独立候选。系统打印对话框物理结果仍受 BUG-0002 限制，不以 DOM 或 PDF 推断为已通过。

## 发布门

代码和替身测试通过仅是本地候选。2026-09-30 已在隔离内置浏览器的真实 `vue-print-designer@1.7.39` 中验证合成 7 条、2×3 标签：预览两页、订单/客户各一次且顺序正确；原生引擎 PDF (`artifacts/label-engine-test.pdf`) 经 `pdfinfo` 确认 A4 两页，逐页渲染检查第一页六格、第二页一格，没有观察到裁切或额外空白页。PDF 为图像型，不能用 `pdftotext` 空输出来判空白。

正式记录视图的模板创建、保存重开、真实字段、取消/重选/退出、浏览器系统打印物理页数和一个 PDF 仍待部署后 E2E。合成测试不证明正式环境可用，也不解除 BUG-0002。连续纸后续证据与实现见 ADR-0014；本段仍是标签候选阶段的历史记录。

## 2026-09-30 发布后补证

上述发布门段落记录的是本地候选阶段。随后小组件 `1.0.23` / 应用 `1.0.19` 仅灰度到 `F225904757`，权限无变化。正式 Base 已完成标签模板新建/保存、刷新重开、三条真实记录同纸三格、七条按 2×3 跨两页、取消/重选/退出；导出的 A4 一页/两页 PDF 已逐页核对订单编号和单价，见 PHASE-04 第 29、30、32 节。失败恢复与系统打印物理页数尚未验，BUG-0002 及连续纸证据门均不关闭。
