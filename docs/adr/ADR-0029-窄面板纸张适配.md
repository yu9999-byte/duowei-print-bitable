# ADR-0029 — 窄面板纸张适配

- 状态：本地候选，正式灰度待验
- 日期：2026-10-14

## 决策

1. 预览保留引擎生成的 794px 等自然纸张，按插件可用宽度计算屏幕显示比例；iframe 自身保持完整自然尺寸，仅在屏幕上 `transform: scale`，外层提供缩放后占位，避免 iframe 内裁切和第二个纵向滚动。
2. 编辑继续使用 `vue-print-designer`。进入编辑时只调整传给设计器的初始 `zoom`，按宿主宽度扣除内部轨道、画布 padding 和滚动条后向下取 5% 刻度，最低 20%。用户仍可用设计器原有缩放和平移控件查看细节。
3. 预览缩放绝不进入打印/PDF 页面；打印/PDF 仍按模板自然纸张和既有页盒实现。
4. `BUG-0013` 的选择改图层单独处理，不通过忽略所有层级差异来掩盖未保存状态。

## 验收

`SPEC-UX-15`、`tests/preview-fit.test.ts` 和独立测试 Base 的单条、三条预览及编辑宽度回归。发布前仅为本地候选。
