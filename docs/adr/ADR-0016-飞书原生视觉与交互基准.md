<title>ADR-0016 — 飞书原生视觉与交互基准</title>

- 状态：partially superseded by ADR-0017/0018（飞书视觉基准与单条模式仍有效；批量目录及动作归属以 ADR-0018 为准）
- 日期：2026-10-07
- 关联：ADR-0007、ADR-0008、ADR-0009、BUG-0005、SPEC-UX-08/09/10

# 背景

当前正式工作台已经具备单条预览、模板目录、模板编辑、数据源/组件、批量预览和输出能力，但 Goal v6 的视觉候选把嵌入式飞书插件做成了独立后台：品牌标题过大，状态常驻，模板行永久展开多个浏览器原生按钮，新建模板入口重复，预览区域出现内外双滚动，顶部与工作区操作层级互相争抢。功能存在并不等于交互成立；继续局部补 CSS 会固化入口冲突。

# 决策

1. 多维打印按“飞书内嵌生产力工具”设计，不按落地页、营销页或通用 Dashboard 设计。产品框架退居背景，纸张和当前任务是主内容。
2. 保留四种清晰表面：单条预览、单条编辑、批量预览、批量编辑。模式决定可见动作，不允许同一意图在同一状态出现两个入口。
3. 单条预览显示模板目录；模板行只负责选择，重命名、设为默认和删除进入同一个“更多”菜单。目录只有一个“新建模板”入口，再选择默认、连续或标签类型。
4. 单条编辑隐藏模板目录与输出动作。左侧只放产品级“数据源/组件”，右侧继续使用真实 `vue-print-designer`；顶部只保留返回、模板状态与唯一保存动作。设计器使用公开 `setTheme("light")` 与受控 UI Chrome 适配：默认关闭遮挡画布的属性/结构浮层，隐藏与外壳重复的导出、预览、打印、语言、主题和帮助入口，但不修改其渲染、字段绑定或输出算法。
5. 批量预览保留与单条预览相同的左侧模板目录；已选数量、重新选择/退出/打印/PDF 和当前模板编辑集中在右侧当前模板工具栏。批量编辑隐藏模板目录，左侧切换为唯一数据源/组件操作面，右侧为真实设计器，并显示返回与唯一保存；模板切换与输出只在批量预览有效。完整批量规则以 ADR-0018 为准。
6. 普通成功态不占用永久状态横幅；自动刷新是默认行为。失败、读取中或需要恢复时，才在失败对象附近显示状态与重试。
7. 使用统一 Token：14px 正文、12px 辅助、16px 区域标题、32px 控件、4px 间距体系、`#3370FF` 主色和克制的中性色；禁止裸浏览器按钮、无信息意义的大圆角卡片、渐变、重阴影和装饰性大标题。
8. 插件根节点不拥有第二个页面纵向滚动；模板/编辑侧栏只滚动自身内容，预览工作台只有一个纵向滚动容器，纸张 iframe 不再内部纵向滚动。
9. 先在 `932×540` 真实容器制作预览、编辑和批量视觉证据，并补测 700px 与宽屏。用户明确确认视觉方向后，才允许修改正式产品 UI。

# 替代方案

- 继续修补 Goal v6：拒绝。该方案的问题来自信息架构和动作所有权，不是颜色或圆角的局部问题。
- 直接引入 Semi React：拒绝。当前项目为 Vue，Semi 只作为字节系原则和 Token 参考，不为外观迁移框架。
- 重做打印设计器：拒绝。`vue-print-designer@1.7.39` 仍是唯一真实画布，本轮只改产品外壳和展示交互。

# 后果

- 视觉改造必须先有批准稿，再按 TDD 改结构和样式。
- 工作台测试不仅断言控件存在，还要断言模式动作唯一、统一控件、滚动所有权和窄容器可达。
- 本 ADR 不授权修改字段 Token、模板协议、记录读取、批量会话、打印/PDF、权限、应用配置或发布流程。
