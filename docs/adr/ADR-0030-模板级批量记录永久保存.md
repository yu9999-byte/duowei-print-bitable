# ADR-0030 — 模板级批量记录永久保存

- 状态：已决策，正式灰度核心验收通过
- 日期：2026-10-15
- 取代：`SPEC-BATCH-08/10` 与 SDD 中“切换模板立即丢弃批次、不保存记录 ID”的现行行为；历史 Goal v18 验收记录保留为当时事实

## 决策

1. 模板画布、批量排版方式和有序的所选记录 ID 都归属同一个模板。选择器确认后自动保存所选 ID；模板预览展示已选数量与实际内容，不常驻展示“记录已保存”，失败才明确提示。没有已存模板时，确认选择将当前自动/草稿模板创建为持久模板。
2. 记录 ID 是选择配置，保存在 Base/table 作用域的模板集合条目元数据 `savedBatchRecordIds`，而不是设计器模板的 `pages/ext`，也不保存记录字段值、关联明细内容或批量投影。上限 50，按选择顺序去重和校验；共享集合的修订号参与并发写保护。
3. 切换模板时只读取目标模板的选择。目标未保存批次则显示宿主单条；切回原模板恢复原批次。关闭和重开插件按当前默认模板恢复其已保存批次。每次预览、编辑、打印、PDF 都通过飞书 SDK 重新读取真实值。
4. 点击“退出批量”清除当前模板存储的 ID，并返回宿主单条；读取、渲染或存储失败不提交目标状态。记录失效或无权限时保留配置并显示可行动警告，单条可继续使用。
5. `saveTemplate` 和排版方式更新保留 `savedBatchRecordIds`；删除模板随条目删除选择。自动化保持暂停，批量记录选择不进入自动化 Registry 或输出文件模板。

## 权衡

Base/table 下的模板集合为共享作用域，具备模板读取权的成员会看到同一批次选择；这与共享模板语义一致。只持久化记录 ID；成员对记录的实际读取仍受飞书权限控制。若未来需要成员个人批次，应另设用户作用域存储，不复用共享模板字段。
