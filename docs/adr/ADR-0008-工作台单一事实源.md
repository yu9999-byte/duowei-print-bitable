<title>ADR-0008 — 工作台单一事实源与草稿生命周期</title>

- 状态：accepted（本轮实现范围）；输出分页和完整页面设置仍由独立缺陷/后续规格负责
- 日期：2026-09-23

# 背景

工作台改造后同时出现外层模板目录、设计器内置模板列表、外层数据源摘要和设计器内部变量面板。顶部“编辑”、模板卡片和“新建模板”又可以从不同路径改变同一份内存模板，未保存修改没有统一的退出保护。这个结构会让用户无法判断哪一个入口、状态和数据源是最终事实。

# 决策

1. 外层模板目录是当前表唯一活动模板的产品事实源；MVP 不在设计器内启用第二套模板列表。
2. 预览模式必须先选中模板，只有模板卡片的“编辑模板”动作可以进入编辑模式；顶部不再提供绕过模板选择的编辑入口。
3. 当前编辑使用已保存基线和内存草稿两个明确概念。返回预览、重新加载和上下文切换遇到脏草稿时，统一显示保存、放弃或继续编辑的决策。
4. 数据源目录由当前 `PrintJob` 生成，分为“字段”和“系统”，外层字段行支持按引擎拖拽契约绑定到真实画布；设计器内置模板目录隐藏，避免第二套数据源/模板目录。
5. 页面设置本轮只保留统一入口和当前摘要，不伪装成完整纸型编辑；完整纸型、方向、边距和缩放另立规格。

# 后果

- 工作台状态需要记录模板选择、编辑模式、脏状态和待处理决策，不能只用一个模式布尔值。
- 退出编辑、模板重载和上下文变化必须经过同一个守卫函数。
- 设计器仍是唯一画布和排版引擎；外层不复制画布实现。
- 本决策不关闭 `BUG-0002`，也不把真实飞书 E2E 视为本地测试通过。

# 验收

- `SPEC-UX-04/05`、`SPEC-SRC-03` 有失败测试和回归证据。
- 真实记录视图中只显示一个模板目录，模板编辑必须从模板卡片进入。
- 脏草稿退出、重载和切换上下文时不会静默丢失。
