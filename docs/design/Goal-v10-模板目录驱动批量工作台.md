# 设计目标

批量不是另一套导航，而是“当前模板应用于多条记录”。单条预览、批量预览和批量编辑共享同一模板目录；右侧当前模板工作区承担记录上下文、批量动作、预览或编辑。

# 动作所有权

| 状态 | 左侧 | 右侧当前模板工具栏 | 右侧内容 |
|-|-|-|-|
| 单条预览 | 模板目录 | 当前记录、选择记录、PDF、打印、编辑模板 | 单条预览 |
| 单条编辑 | 数据源/组件 | 返回预览、唯一保存 | 真实设计器 |
| 批量预览 | 同一模板目录 | 已选 N 条、重新选择、退出、PDF、打印、编辑模板 | 当前模板批量预览 |
| 批量编辑 | 同一模板目录 | 已选 N 条、返回批量预览、唯一保存 | 数据源/组件＋真实设计器 |

顶层产品栏仅保留“多维打印”身份。批次记录摘要不是导航；需要时可从“已选 N 条”查看，不占据左侧目录。

# 视觉稿

- `Goal-v10-batch-preview-932.svg` / `Goal-v10-batch-edit-932.svg`：主验收尺寸 932×540。
- `Goal-v10-batch-preview-700.svg` / `Goal-v10-batch-edit-700.svg`：窄容器 700×540。
- `Goal-v10-batch-preview-1200.svg` / `Goal-v10-batch-edit-1200.svg`：宽容器 1200×700。

六张稿均使用 8 个模板、标签模板 3、3 条记录和飞书式 Token。预览展示同一 A4 内三个标签；编辑展示左侧模板目录不变、右侧唯一数据源/组件操作面与真实设计器占位。视觉稿是产品壳层证据，不是独立 Demo，也不替代真实 `vue-print-designer`。

# 交互与异常状态

| 状态 | 模板目录 | 右侧工具栏 | 右侧内容 | 恢复规则 |
|-|-|-|-|-|
| 正在切换模板 | 原模板仍保持选中；目标行显示局部加载 | 打印、PDF、编辑和再次切换暂时禁用 | 保留上一份可打印预览，不显示空白 | 新模板整批渲染成功后一次性切换；失败恢复原选中 |
| 切换模板失败 | 原模板继续选中；目标行显示错误标记 | 原输出动作继续可用 | 保留上一份可打印预览；工具栏下方显示“未能切换模板”和“重试” | 重试只重建同一候选，不清空批次或改变记录顺序 |
| 正在创建模板 | 不先插入幽灵目录项；新建入口显示加载 | 当前模板动作仍与原工作区一致 | 原预览保持 | 完整创建事务成功后才新增目录项并进入编辑 |
| 创建模板失败 | 目录和选中项完全不变 | 新建入口恢复可用 | 原预览保持；新建入口附近显示“创建失败”和“重试” | 重试复用同一模板类型，不重复创建草稿 ID |
| 批量编辑有未保存修改 | 当前模板行显示“未保存”；其他模板行仍可聚焦 | 只显示返回预览和唯一保存，隐藏输出 | 保留真实设计器与草稿 | 切换模板、返回或退出先进入统一草稿决策 |
| 保存或重渲染中 | 模板目录不可切换 | 保存按钮显示加载并禁用重复提交 | 设计器保持可见但禁止产生第二次提交 | 保存成功且整批渲染成功后返回预览；失败保留草稿和旧批次 |
| 无模板 | 只显示自动模板状态与唯一新建入口 | 仅暴露当前自动模板有效动作 | 显示自动模板预览 | 不把空目录误当作加载失败 |

控件状态统一遵循飞书式交互：模板行和按钮的 hover 使用浅中性色背景；当前模板使用浅蓝背景、左侧 3px 主色标识；键盘 `focus-visible` 使用 2px 主色焦点环；禁用态保留标签但降低对比度且不响应点击；加载只发生在被操作对象附近，不用全屏遮罩替换可恢复内容。700px 工具栏可换为同一容器内的两行，不隐藏动作、不截断按钮文字，也不把动作移回顶层产品栏。

# 新建模板失败设计

三种模板类型先生成明确模板对象，再执行设计器加载、真实数据绑定和首屏渲染。事务成功后才切换目录选择、草稿 ID 和编辑态；任一步失败保持原模板和原预览，在当前模板工具栏附近显示错误与“重试创建”，不得先清空画布。

# 待确认

1. 批量预览/编辑左侧始终是模板目录。
2. 批量预览允许切换模板且不重新选择记录。
3. 表/记录或已选数量、选择/重选、退出、PDF、打印、编辑位于同一右侧模板工具栏。
4. 700px 下工具栏分为上下两行，但仍属于同一容器；操作不移到全局产品栏。

用户确认视觉方向后，才允许修改产品 UI 与测试实现。
