# 设计目标

模板目录只服务于预览态的模板选择与管理。用户进入单条或批量编辑后，目录隐藏，左侧只保留唯一“数据源 / 组件”操作区，右侧把更多空间交给真实 `vue-print-designer`。退出编辑后恢复原模板目录选择；批量会话的记录、顺序和排版不变。

# 四表面动作所有权

| 状态 | 左侧 | 工具栏 | 主内容 |
|-|-|-|-|
| 单条预览 | 模板目录 | 当前记录、选择记录、PDF、打印、编辑模板 | 当前模板单条预览 |
| 单条编辑 | 数据源 / 组件 | 当前模板、返回预览、唯一保存 | 真实设计器 |
| 批量预览 | 同一模板目录 | 已选 N 条、重选、退出、PDF、打印、编辑模板 | 当前模板批量预览 |
| 批量编辑 | 数据源 / 组件 | 当前模板、已选 N 条、返回批量预览、唯一保存 | 真实设计器 |

编辑态不提供模板切换、打印、PDF 或记录选择。返回预览后才能切换模板；存在未保存草稿时，返回动作先进入统一的“保存并继续 / 放弃修改 / 继续编辑”决策。

- `artifacts/design-v11/Goal-v11-batch-preview-1200.*` / `Goal-v11-batch-edit-1200.*`：宽容器 1200×700。

预览稿继续使用 8 个真实模板、标签模板 3 和 3 条已选记录；编辑稿隐藏整个模板目录，以字段/系统数据源和组件面板替代，并扩大真实设计器区域。视觉稿只证明产品壳层、信息结构和空间分配，不替代真实设计器或端到端证据。

# 状态与恢复

| 场景 | 保持内容 | 可见反馈 | 成功提交点 |
|-|-|-|-|
| 进入批量编辑 | 当前模板、3 条记录、顺序、排版、上一份可打印预览 | 目录隐藏，左侧变为数据源/组件 | 设计器完成当前模板加载后进入可编辑态 |
| 返回批量预览 | 编辑前模板目录选择和批次会话 | 有脏草稿时显示统一决策 | 保存或明确放弃后恢复目录；继续编辑则不离开 |
| 保存模板 | 草稿、旧批次页面和记录会话 | 唯一保存按钮显示加载 | 模板保存且整批重渲染成功后替换预览 |
| 保存或重渲染失败 | 草稿、旧批次页面、原模板选择 | 工具栏附近显示错误与重试 | 重试成功前不显示新模板配旧页面 |
| 预览切换模板 | 原记录、原模板、旧预览 | 目标模板行显示局部加载 | 目标模板完整重渲染成功后一次性切换 |
| 新建模板失败 | 原目录、原模板、原预览和原批次 | 新建入口附近显示失败与重试 | 生成、加载、绑定、首屏全部成功后才插入草稿 |

# 窄屏规则

700px 下不缩成不可读的双侧栏。编辑态只有一个约 156px 的数据源/组件侧栏；标题和返回/保存位于同一工具栏的上下两行，按钮文字保持完整。设计器画布拥有剩余宽度及唯一内部滚动，不再为隐藏的模板目录预留空间。

# 确认与实现结果

1. 单条和批量编辑均隐藏模板目录。
2. 批量编辑左侧只显示数据源/组件，右侧为扩大的真实设计器。
3. 返回预览恢复原模板目录选择，批量记录、顺序和排版保持。
4. 编辑态不提供模板切换、打印、PDF 或记录选择。

用户已确认上述视觉方向。实现已在现有 Vue 栈和真实 `vue-print-designer@1.7.39` 上完成：四表面动作矩阵、模板原子创建/切换、未保存草稿守卫与三尺寸布局均已通过；实现截图见 `artifacts/implementation-v11/`。该证据为本地候选，不代表正式灰度已经更新。
