# 目标

批量工作台表达“当前模板应用于多条已选记录”。左侧批次目录在预览和编辑间保持位置、宽度、信息与滚动上下文；右侧模板区域在批量预览和模板编辑间切换。

# 动作所有权

| 状态 | 左侧 | 右侧 | 顶部动作 |
|-|-|-|-|
| 批量预览 | 记录数、模板、排版、记录摘要 | canonical pages | 重新选择、退出批量、PDF、打印；右侧唯一“编辑模板” |
| 批量编辑 | 与批量预览完全相同 | 内嵌数据源/组件操作面＋真实设计器 | 返回批量预览、唯一“保存模板”；隐藏输出 |

批量编辑的操作面位于右侧编辑区域的左缘，因此不会替换左侧批次目录，也不会把数据源/组件散到设计器顶部。保存仍进入既有仓库用例；保存成功后使用同一批记录和同一布局完整重渲染，成功才替换批次预览。

# 本地实现验收

2026-10-08 在独立本地宿主中挂载真实 `vue-print-designer@1.7.39`，并使用三条模拟记录执行完整用户路径：

- 932×540：批量预览为 3 条/3 页；进入编辑后左侧仍为同一批次目录，宽 188px，右侧操作面宽 176px。真实文本组件按 Enter 插入换行，失焦显示当前值；保存后无需重新选择，三条页面均显示新换行内容。
- 700×540：批次目录宽 164px，右侧操作面宽 148px，真实设计器获得剩余 388px；返回批量预览与唯一保存按钮均可达，`body` 无横向或纵向溢出。
- 默认、标签、连续三种排版均完成“批量预览 → 编辑模板 → 保存 → 原三条记录批量预览”；页数分别为 3、1、1，模板与排版标签没有降级。
- 自动化证据为 `npm test` 180/180、生产构建和 `git diff --check` 通过；正式环境仍是上一灰度版本，本节不构成正式 E2E。

# 约束

- 不在批量目录开放新建、删除、重命名或切换模板；批量编辑只修改当前模板。
- 不显示第二个保存、数据源、组件或输出入口。
- 编辑态打印/PDF隐藏，避免把旧 canonical pages 当作新模板结果。
- 设计证据不是独立 Demo；实现继续挂载真实 `vue-print-designer@1.7.39`。
