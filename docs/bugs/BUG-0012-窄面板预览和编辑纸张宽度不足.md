# BUG-0012 — 窄面板纸张可视区域不足

- 状态：灰度修复并在独立测试 Base 复验通过（2026-10-15）
- 日期：2026-10-14
- 环境：独立测试 Base `GmpDbJRMiaBQSgsTnnncwdn1nCd`，记录 `CAP-001`；2026-10-14 控制台最新灰度应用 `1.0.58` 绑定记录视图 `1.0.54`

## 复现

在约 635px 宽的飞书记录面板中，预览 iframe 仅有约 441px，而内部 A4 纸张宽 794px；预览右侧直接被隐藏。进入编辑时，设计器默认 100% 缩放，794px 纸张超出约 458px 的内部画布可视宽度，用户需手动横向滚动才能看到整张纸的宽度。

## 修复候选

预览只缩放屏幕上的 iframe 外观，外层按缩放后的纸张尺寸占位并保留唯一纵向滚动；编辑进入时使用真实设计器的 `zoom` 初始值使纸张宽度适合宿主宽度，保留设计器自己的缩放和滚动。打印和 PDF 仍使用自然纸张尺寸。见 ADR-0029、`src/components/preview-fit.ts`。
