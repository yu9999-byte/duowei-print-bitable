<title>BUG-0005 — 工作台整体视觉风格需要统一</title>

- 状态：已记录，暂不修改
- 日期：2026-09-25
- 关联：SPEC-UX-01/03、ADR-0009、PHASE-02F

# 用户反馈

当前工作台整体风格不理想，问题不只在单个按钮或局部组件，主要涉及页面整体层级、字体大小、字重、间距、颜色、工具栏密度、预览区与编辑区的视觉关系，以及不同模式之间的统一性。

# 当前判断

这是视觉系统层面的后续改造，不应在多字段绑定逻辑未稳定前零散调整。现有 CSS 已形成一套局部样式，但尚未经过正式 Base 的完整交互验收和统一视觉评审；本问题暂不改变功能验收结论，也不在本轮修改样式。

# 后续边界

后续应以“预览模式/编辑模式”为整体对象统一评审字体层级、密度、颜色、边框、状态和响应式布局，避免逐个按钮修补；改造前先补视觉验收基线和截图，不与 BUG-0004 的字段绑定方案混合发布。
