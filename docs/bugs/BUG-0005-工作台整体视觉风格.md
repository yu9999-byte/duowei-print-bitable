# 用户反馈

当前工作台整体风格不理想，问题不只在单个按钮或局部组件，主要涉及页面整体层级、字体大小、字重、间距、颜色、工具栏密度、预览区与编辑区的视觉关系，以及不同模式之间的统一性。

# 当前判断

这是视觉系统层面的独立改造，不与字段、模板、批量或打印算法混做。Goal v6 已以 GitHub Tag `baseline-pre-style-redesign-2026-10-07` 为回退点，在 `codex/modern-workbench-style` 建立共享视觉 Token，重做顶部操作层级、模板选中态、编辑侧栏、纸张画布、批次/加载/错误状态、焦点与窄容器布局。真实 `vue-print-designer` 保留并固定为浅色表面，避免与外层工作台割裂。

# 后续边界

本地 `CT-UX-08` 已覆盖 Token、主次操作、模板次要动作键盘可发现、减少动态效果和设计器主题一致性；隔离真实引擎页面已经检查预览、编辑、组件、批量和窄容器，并保存前后截图。当前没有上传或灰度发布，因此只能表述为“本地候选已修复”。发布后必须在不带 `debugPort` 的正式 Base 执行 `E2E-UX-02`，确认真实宿主无裁切、无入口回归后再关闭本问题。
