- 状态：已关闭（Goal v7 已完成正式灰度 E2E）
- 日期：2026-09-25
- 关联：SPEC-UX-01/03、ADR-0009、PHASE-02F

# 用户反馈

当前工作台整体风格不理想，问题不只在单个按钮或局部组件，主要涉及页面整体层级、字体大小、字重、间距、颜色、工具栏密度、预览区与编辑区的视觉关系，以及不同模式之间的统一性。

# 当前判断

这是视觉系统与动作层级共同造成的问题，不是单个按钮的皮肤缺陷。用户截图进一步确认：品牌标题过大、读取/刷新重复、模板管理动作永久展开且存在浏览器原生按钮、三个新建入口并列、标题层级竞争，以及纸张顶部裁切和内外双滚动。Goal v6 候选未达到飞书插件标准，保留为失败证据，不合并、不发布。

# 后续边界

Goal v7 已按用户选择的方案 B“画布优先”完成本地与正式实现：三模式动作所有权、飞书 Token、紧凑模板目录、单一新建/管理、短暂状态、单一滚动与真实亮色设计器均已验证。全量 171/171 与生产构建通过；小组件 `1.0.37` / 应用 `1.0.34` 已仅灰度到 `F225904757`，权限变更“暂无”。正式 `PO-0001` 已通过单条预览、编辑态唯一操作区和默认/标签/连续三种真实批量预览，E2E-UX-02 关闭。本缺陷关闭不代表 BUG-0002、BUG-0007、50/51 条、关联明细或许可证门关闭。
