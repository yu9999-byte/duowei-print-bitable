# BUG-0009：新建默认模板响应式代理复制失败

## 状态

`closed`（2026-10-08）

## 用户现象

在正式 Base 的“多维打印”中点击“新建模板 → 默认模板”，页面提示：

`Failed to execute 'structuredClone' on 'Window': [object Object] could not be cloned.`

原模板、预览和正式业务数据未被覆盖，但用户无法进入新默认模板编辑态。

## 复现版本

- 小组件：`1.0.39`
- 应用版本：`1.0.36`
- 详情 ID：`7694188677224697025`
- 正式入口构建：`assets/main.c75628ce.js`
- 记录：`PO-0001`

## 根因

`vue-print-designer.getTemplateData()` 在真实浏览器中可能返回 Vue/Web Component 的响应式 `Proxy`。该对象的内容满足模板 JSON 协议，但浏览器 `structuredClone` 按规范拒绝直接复制代理。此前本地测试返回普通对象，所以只覆盖了模板结构，没有覆盖运行时对象形态。

## 修复

新增 `cloneJsonValue` 作为宿主/设计器 JSON 数据边界：

1. 普通对象优先使用 `structuredClone`。
2. 原生克隆拒绝代理时，回退到 `JSON.stringify/parse`。
3. 两条路径均失败时显式报错，不静默复用原可变对象。
4. 模板绑定/快照、数据源刷新/输出准备、连续布局、打印任务和模板仓储统一使用该边界。

该修复不改变模板存储协议、业务字段、权限、打印排版或产品交互。
