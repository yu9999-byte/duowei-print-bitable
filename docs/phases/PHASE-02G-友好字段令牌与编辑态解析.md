# 定位

- 复制生产路径只写 plain text 内部 Token，未携带可供真实编辑器恢复的字段标签结构。
- 真实设计器没有被接管粘贴、内容编辑、失焦和再次编辑生命周期。
- 当前解析只包围预览、打印和 PDF 输出，编辑画布不调用。
- 现有 84/84 测试覆盖纯函数和输出临时模板，但缺少锁定引擎编辑契约与正式交互用例。

# Goal v3 实施顺序

1. 技术调查：在锁定的 `vue-print-designer@1.7.39` 中确认文本组件选择、内容输入、paste/input/blur、模板变更和重载的公开 API/事件；记录最小可维护接入点。
2. Red：新增稳定 ID↔友好标签↔当前值的可逆测试；覆盖多 Token、静态分隔符、系统项、改名、同名、删除、无权和未知 Token。
3. Red：用真实安装包补选中→粘贴→失焦→再次编辑→`getTemplateData`→重载契约；断言用户界面不出现内部 Token，模板不出现当前记录值。
4. Green：新增 DataSourceTokenCodec；扩展 DesignerAdapter 的编辑生命周期。`App.vue` 只传当前 DataSourceCatalog/PrintJob 和状态，不直接操作引擎内部 DOM。
5. 兼容：原样读取 Goal v2 稳定 Token 模板；字段改名更新标签不改 ID；失效字段保留原 ID 并显示错误，不迁移到其他字段。
6. 回归：现有 84 项加新测试全部通过；构建成功；多模板、草稿守卫、组件拖拽、预览、打印/PDF 与批量输出不回归。
7. 发布：按固定流程上传并绑定新小组件，仅创建灰度应用版本，不新增权限、不全量发布。
8. 正式 E2E：复制“订单编号”和“客户名称”到同一文本组件，核对编辑标签、失焦值、再次编辑、保存重开、切换 `PO-0002`、打印预览、浏览器打印和 PDF；页面与产物不得出现内部 Token。

# 停止条件

若公开 API 和单一版本固定适配都不能稳定区分内容编辑、失焦与模板保存，停止实现并报告尝试、引擎证据、维护风险和可选产品折中；不得把独立输入框、脚本派发事件或直接改 DOM 结果当作真实设计器闭环。BUG-0002 和 BUG-0005 不在本阶段修改。
