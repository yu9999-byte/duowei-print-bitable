# 关联明细字段与循环行

日期：2026-10-15。状态：本地实现与验证完成，未发布，未进行正式飞书环境验收。

## 使用方式

单向关联、双向关联是特殊的数据源。字段面板以关联字段原名显示分组，展开后显示关联表的字段。点击任意子字段即可复制，操作方式与普通字段一致。

在编辑器中放置表格，双击数据行的单元格并粘贴所需字段。例如同一行分别放置“商品明细.商品”“商品明细.数量”。预览和输出时按当前记录的关联记录顺序展开，每行各列始终取自同一条关联记录。

同源的连续模板行作为一个循环区域，逐条关联记录重复；静态行保留。空关联不生成假数据行。同一循环行混用不同明细来源会提示错误，应分成不同表格或区域。

## 实现约定

- 面板开放关联表全部可读取字段；自动生成的表格默认选前五列，用户可自行复制其余列。
- 使用关联字段 ID 与子字段 ID 保存绑定，显示友好名称；字段改名不改变绑定。
- 模板保存 `detailTemplateRows` 占位行，不保存业务样本数据；重新打开恢复可编辑占位行。
- 输出前为每份文档独立展开数据，不把第一条记录的明细复用到其他记录。
- 单向、双向关联的方向与多选数量独立：跨表关联即使只能选一条也作为明细源。
- 同表原生父记录引用保留既有标量处理。关联内的关联只显示可读文本，不递归展开。
