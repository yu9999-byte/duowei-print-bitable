# 目标

让含关联/双向关联字段的主记录在同一模板中完整打印主表与明细表，并在单条、默认批量、编辑、浏览器打印和 PDF 中保持同源、完整、可解释。

# TDD 顺序

1. 文档基线：SPEC v0.22、ADR-0024、SDD、TEST、TRACE 与 TODO 冻结读取、分页和失败边界。
2. Red：重复 ID、关联读取超时、无目标视图、双主记录明细隔离测试先失败。
3. Green：最小修复 ID 校验和超时穿透，保持既有字段级降级与整任务失败语义。
4. Refactor：确认单条与默认批量共用 PrintJob/table variable，不引入预览专用或输出专用模型。
5. Verify：定向测试、全量测试、构建、diff-check 和真实设计器 0/1/长/双主记录夹具。
