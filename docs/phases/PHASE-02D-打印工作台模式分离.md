# 目标

把当前记录视图插件从“默认打开完整设计器”调整为“默认打印预览，按需进入编辑”。同时提供当前表唯一活动模板的目录和状态，并统一编辑入口。

# Red

新增 `tests/workspace.test.ts`，要求工作台状态模型能够：

- 默认进入 `preview`，只有显式动作才进入 `edit`；
- 在无模板、自动模板、已保存模板、只读回退和未保存编辑之间显示稳定状态；
- 编辑入口只暴露数据源、组件、页面设置和设置四个一级分区。

# Green

- `src/core/workspace.ts` 提供 `preview`/`edit` 状态切换、四种模板状态和稳定编辑入口顺序。
- `src/engine/designer-adapter.ts` 新增 `getPrintPreviewHtml`：单条预览只读取真实 `vue-print-designer` HTML，不创建 Blob、不触发打印窗口。
- `src/App.vue` 已接入双模式工作台：默认打印预览；显式“编辑”后显示真实设计器；返回预览会重新读取引擎 HTML。
- 模板目录只呈现当前表唯一活动模板，支持自动模板、已保存、只读回退、未保存草稿状态；“新建模板”只在内存创建草稿，保存仍走现有 bridge 仓库。
- 编辑模式提供“数据源、组件、页面设置、设置”四个统一外层入口；数据源按当前 PrintJob 的字段和系统值展示，不写死字段。
- 模板编辑交互通过设计器元素的 `input/change/pointerup/keyup` 事件与模板快照比较，标记本地未保存状态；引擎事件名未被臆造。

证据：

```text
npm test       -> 58/58 passed
npm run build  -> webpack production build succeeded
```

# Refactor

- 保留真实 `vue-print-designer@1.7.39` 作为画布和渲染引擎，外层只负责工作台状态编排。
- 预览模式与编辑模式共用一个设计器实例，避免重新挂载导致模板/数据源丢失。
- 未修改 `BUG-0002` 的分页和打印 CSS；本切片不把预览与打印页数一致性标记为完成。

# 真实 E2E

本阶段的真实验收计划已被 ADR-0009 的多模板切片取代；不再以“四个入口”作为现行验收。当前默认预览、两模板、真实数据源/组件、唯一保存和输出验收统一记录在 PHASE-02F/PHASE-03；组件已在后续版本发布，本文件仅保留历史切片证据。

# 不在本阶段

`BUG-0002` 分页修复、多模板存储、模板共享权限、签名区域、检测器高级能力和全量纸型支持。
