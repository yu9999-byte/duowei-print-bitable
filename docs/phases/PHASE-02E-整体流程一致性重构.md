本阶段为历史过程记录；其中“字段行使用真实引擎拖拽数据格式”已被 ADR-0009 和 Goal v2 取代，现行规则是组件拖拽、数据源复制/粘贴。

# 目标

在发布下一版工作台前，收敛模板、数据源和草稿生命周期的事实源，兼顾已完成的真实数据读取、模板存储、预览和浏览器打印逻辑。

# Red

本轮先补充以下失败契约：

- 模板目录只有一个产品事实源，设计器内置模板面板被隐藏。
- 未选中模板不能直接进入编辑；模板卡片编辑动作才允许进入编辑。
- 脏草稿离开、重载或上下文变化必须经过决策。
- 数据源目录只来自当前 `PrintJob`，字段行使用真实引擎拖拽数据格式。

Red 证据：新增契约首次运行时，工作台选择/草稿守卫、数据源拖拽、模板面板抑制和 base/table 存储接口尚未满足测试；完成生产代码后进入 Green。

# Green

1. 工作台增加明确模板选择；未选中模板时不能进入编辑，“编辑模板”成为模板目录内的唯一编辑入口。
2. 返回预览、重新加载、重新读取、批量选择和宿主上下文变化统一经过脏草稿守卫，支持保存、放弃或继续编辑。
3. `DesignerAdapter` 关闭并抑制设计器内置模板面板，保留真实画布、组件、属性和排版能力。
4. 外层字段/系统目录按 `vue-print-designer` 的真实 MIME 契约支持拖入画布，不再只是静态摘要。
5. 活动模板键改为 `baseId/tableId`，旧 table-only 键只读兼容，下一次保存写入新键；新增跨 Base 隔离测试。

# 证据

- `npm test`：64/64 通过。
- `npm run build`：通过；仅有现有依赖块体积告警。
- 生产调用已全部使用 `{ baseId, tableId }`；不存在旧 `tableId` 单参数调用。
- 本轮未上传组件、未创建应用版本、未发版；真实飞书记录视图中的模板选择、拖拽和草稿守卫仍需 E2E。

# 不在本阶段

- `BUG-0002` 预览/打印页数偏差。
- A4/A5/B5/Letter、方向、页边距和缩放的完整编辑。
- 多模板存储、共享和权限模型。
- 真实飞书记录视图 E2E、灰度上传和应用发版。
