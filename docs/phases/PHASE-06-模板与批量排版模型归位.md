<title>PHASE-06 — 模板与批量排版模型归位</title>

# 目标

把“模板创建方式”和“批量排版方式”拆成两个独立概念：用户只创建空白或自动生成模板；默认、连续、标签只作用于当前模板的批量输出。

# TDD 顺序

1. 文档基线：ADR-0023 与 SPEC/TEST/TRACE 先冻结状态模型和兼容规则。
2. Red：新建菜单只有两种创建方式；批量排版切换保持模板 ID/数量不变；不同模板设置隔离；旧模板无损识别。
3. Green：新增独立的模板创建类型和批量排版设置模型，移除编辑态“新建另一排版模板”的业务路径。
4. Refactor：把渲染、编辑投影和存储统一接入当前模板的批量设置，消除结构推断的第二事实源。
5. Verify：定向测试、全量测试、生产构建和本地真实设计器回归；发布另行授权。
