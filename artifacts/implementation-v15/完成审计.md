# 用户豁免项（未验证）

- `E2E-TPL-SHARE-01`：两个不同飞书成员在同一正式 Base、同一数据表内看到同一模板目录。
- 权限边界：权限不足成员可读取/打印，但创建、编辑、重命名、设默认、删除被拒绝时，模板集合保持不变并显示明确错误。

# 保留证据

1. 飞书官方把 `bridge.setData` 描述为“在当前 base 中存储自定义内容”，项目 key 也不包含成员身份；这些证据支持共享设计，但官方资料没有直接承诺两个不同成员一定读取同一值。
2. 当前没有第二个可访问该测试 Base 的正式成员身份，无法完成跨成员和权限差异验收。

# 未来若重新启用

1. 准备第二个可访问同一测试 Base 的飞书成员身份；若要验权限边界，其中一个成员需为受限权限角色。该条件不再阻塞 Goal v15。

正式双成员结果若证明 bridge 按成员隔离，再按 `bridge-共享作用域审计.md` 的最小后端方案进入新 Goal；在证据出现前不提前建设后端。
