# 产品验收

1. “新建模板”菜单只显示“空白模板、自动生成模板”，不再显示默认/连续/标签模板。
2. 创建并保存一个自动模板后，默认、连续、标签分别得到三页完整纸张、一张连续长纸、一页三格标签；标签切回默认恢复三页。
3. 三种排版进入编辑模式均显示全部三条记录：默认三张完整页面、连续一张完整长画布、标签完整三格，均可滚动编辑。
4. 创建第二个自动模板后，把模板 2 切为标签；模板目录数量始终为 2。切换到模板 1 时仍是默认排版和三页，切回模板 2 时恢复标签排版和一页。
5. 测试宿主增加显式 `storage` 命名空间后刷新页面：目录仍显示模板 1“默认排版”、模板 2“标签排版”。刷新不会恢复上一轮三条记录选择；重新选择三条后，模板 2 直接按标签排版输出，符合“模板设置持久化、记录选择只属于会话”的规则。
