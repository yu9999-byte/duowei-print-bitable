# 自动化能力

- 单记录触发；无 recordID、空 tableID、跨 Base/table 模板拒绝。
- 模板按 tenant/Base/table、稳定 ID 和 revision 隔离；记录视图在 bridge 成功后同步已清理模板，重命名更新最新名称/快照，删除发送墓碑；Registry 每个稳定 ID 只保留最新修订，持久化重启后墓碑仍隐藏该模板。
- 只读取和外发模板实际引用字段；tenantAccessToken 只用于飞书记录接口与官方附件上传。
- PDF 输出完整多页；PNG 只输出第一页。
- artifactKey 覆盖记录、模板修订、输出类型和引用字段值；并发重复投递只生成、上传一次，失败可重试。
- 标准模式输出 Attachment、success、status、error、artifactKey，并声明原生 SetRecord 后续步骤；后台模式只受理持久任务，不伪装同步附件结果。
- 后台任务覆盖等待生成、生成中、生成成功和生成失败；重复触发复用同一任务，失败可安全重试，服务重启可恢复待处理任务。
- 后台 Worker 通过 app_ticket 换取商店应用/租户短期令牌，上传 `bitable_file` 后只回写用户选择的附件、状态和错误字段。

# 服务安全

- Registry：HMAC 读写签名、飞书会话换签端口、作用域检查；浏览器只发送 Base/数据表/模板草稿，tenantKey/principalId/canWrite 由后端从已验证会话权威补入并返回完整签名 body，客户端 tenantKey 注入、匿名、只读、篡改、过期和跨作用域请求均拒绝；持久化 Store 已验证重启恢复、并发写不丢项、损坏文件拒绝覆盖，状态文件不含签名密钥。
- OAuth：一次性 state 与 PKCE；服务端交换用户令牌并取得 open_id/tenant_key，再用官方云文档权限接口验证目标 Base 编辑权限；成功会话使用 `__Host-`、HttpOnly、Secure、SameSite=None Cookie 并绑定 Base/table。state 重放、不可信来源、跨作用域复用、无编辑权限及回调 HTML/脚本注入均拒绝。
- 生产入口：只暴露健康检查、OAuth、Registry 换签/写入、Renderer、后台任务和飞书事件八条固定路由；精确凭据 CORS、OPTIONS、路由方法、未知路由和请求体上限均 fail closed。
- Renderer：精确请求签名、默认 2 MiB 上限、默认 30 秒超时、无半成品响应、traceId/stage/code 安全错误。
- Headless：每任务隔离页面并保证关闭；页面协议调用同一 `renderer-browser.ts`。生产服务默认 120 秒渲染保护上限，AbortSignal/超时会关闭页面，避免后台继续占用 Chromium。
- 私有服务使用 `x-duowei-service-signature`；不接收飞书访问令牌。

```json
{
```

引擎的 `imageBlob` 实际为 JPEG；实现按模板纸张比例裁取第一张纸，再通过 Canvas 编码为真正的 PNG，已核对标准八字节文件头。
