# 产物性质

本目录保存“多维打印”正式产品改造前的设计证据，不是新的独立插件 Demo，也不包含业务实现。视觉稿使用现行产品的真实模式、动作和中文示例；用户确认方案 B 后，产品实现证据另见 `实现验收记录.md`。

# 方案 A：目录清晰

- 左侧模板目录 228px，类型和默认状态始终可扫。
- 适合模板数量增加、需要频繁切换或管理的用户。
- 纸张区域略小，但 932×540 下仍完整显示纸张顶部和主要内容。
- 文件：`方案A-单条预览-932x540.png`、`方案A-单条编辑-932x540.png`、`方案A-批量预览-932x540.png`。

# 方案 B：画布优先

- 预览目录收窄至 188px，非选中模板减少元信息，纸张获得更大横向空间。
- 适合以确认预览和快速输出为主的高频使用。
- 编辑态仍保留足够宽的数据源面板，避免复制字段时名称难以识别。
- 文件：`方案B-单条预览-932x540.png`、`方案B-单条编辑-932x540.png`、`方案B-批量预览-932x540.png`。

# 两案共同修复

- 产品名降为普通 15–16px 工具标题，不再是营销式大标题。
- 删除普通态“重新读取/刷新预览”重复入口；读取失败时才就近重试。
- 模板管理收进“更多”菜单，目录仅保留一个“新建模板”入口。
- 编辑态隐藏模板目录、打印和 PDF，只保留返回、状态和唯一保存。
- 数据源只复制，组件页负责拖入；设计器画布仍为唯一真实编辑区域，属性/结构面板默认关闭、按需打开。
- 批量态只读，显示批次摘要、重选/退出和带数量的输出动作。
- 预览工作台拥有唯一纵向滚动，纸张顶部不裁切。

# 响应式与状态证据

- 700×540：两案均保存预览/编辑截图；主要动作可达、模板名和数据源名可读、未出现第二个纵向滚动。
- 1200×700：两案均保存预览/编辑截图；纸张居中，工具栏没有无限拉伸，属性区保持稳定。
- `共享交互状态-932x540.png`：记录按钮 default/hover/pressed/focus/disabled、模板更多菜单、读取中、超时错误、空状态和短暂成功反馈。
