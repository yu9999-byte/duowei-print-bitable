# 现场缺陷与修复

首次验收时，第三实例文本失焦后会短暂停留在 `@订单编号`，且其他实例未立即同步。根因是普通数据源失焦链没有把批量 Shadow DOM 文本提交直接路由到公共模板回收，同时初次投影尚未归一化引擎推断的文本变量。

修复后，批量文本 `focusout` 直接调用 `synchronizeBatchEditProjection`；初始绑定先归一化运行时推断，再接受用户修改。新增 `CT-BATCH-09-EDIT: batch text focusout synchronizes the edited instance through the shared template`，Red→Green。
