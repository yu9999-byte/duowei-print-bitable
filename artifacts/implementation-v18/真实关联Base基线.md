# 本地调试边界

尝试使用 `debugPort=8080` 让同一正式 Base 临时加载本地 Goal v18 构建。Base 能识别 DebugMode，但 Codex 隔离浏览器中的插件容器保持空白；把 `record-view/block.json` 临时改向该 Base 后复测结果相同。随后已恢复原配置、停止本地服务器并关闭验收标签页。

因此本轮得到的是“真实 Base 数据结构＋正式旧版缺陷基线”，不是本地 v18 的真实 SDK 通过证据。修复后的正式证据仍必须在获得独立发布授权、灰度发布 Goal v18 后，在同一 Base 复核：

1. 父记录显示 `O-EMPTY-001` 的可读文本，不生成表格。
2. 空父记录显示“—”。
3. 关联明细继续是原生分页表格，96 行样本不截断、不重复。
4. 新建自动模板不出现打印日期，但系统数据源仍可手动选择。
